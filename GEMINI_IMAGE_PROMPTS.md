## 🎯 **GEMINI IMAGE CREATOR INSTRUCTIONS**

### **How to Use These Prompts:**

1. **Go to Google's Gemini** (gemini.google.com)
2. **Select "Image Generation"** or "Create Images" 
3. **Copy and paste** the exact prompt for each image
4. **Request 7:4 aspect ratio** when possible
5. **Download the generated image**
6. **Save with the exact filename** specified
7. **Add to your assets folder**

### **Tips for Best Results:**
- **Be specific** about professional photography style
- **Mention lighting** (professional, dramatic, warm, etc.)
- **Specify corporate/event context**
- **Request high resolution** for web use
- **Ask for commercial use rights** if available

### **Alternative Approach:**
If Gemini doesn't support aspect ratio specification, you can:
1. Generate the image
2. Use an image editor to crop to 7:4 ratio
3. Ensure the image is at least 1400x800 pixels for quality
