# Equinox Audio Visuals — Marketing Guidelines

**Version:** 1.1 — Human Voice Rewrite  
**Audience posture:** Balanced — weddings, galas, and corporate/institutional share equal dignity. Proof may lead with either a celebration or a chamber/conference without forcing a hierarchy.  
**Brand companion:** [brand-guidelines.md](brand-guidelines.md)

These rules apply to the marketing site and should be reused on Equinox Flow / ERP marketing surfaces (emails, proposals, in-app empty states, CTAs).

**North star:** Write like a producer’s field notes — specific, calm, slightly dry when earned. Not a friendly-expert listicle bot.

---

## 1. Positioning

**One-line:** Event production with character — hospitality-minded technical production across New England and beyond.

**What we sell:** Calm show-day execution, venue fluency, and invisible craft — not commodity gear rental.

**Verticals (equal weight)**

| Vertical | Proof language |
|----------|----------------|
| Weddings | Named venues, timing specifics, ceremony/reception care |
| Galas / nonprofit | Ask moment, fundraising impact, room control |
| Corporate / institutional | Run-of-show, breakouts, speaker support, risk ownership |

Do not bury corporate work to look “wedding-only,” and do not strip warmth to look “enterprise-only.”

---

## 2. Voice — keep list

Always allowed:

- *Character.*
- *Hospitality mindset.*
- *Invisible.* / *The best AV is invisible.*
- *Cool kids, nice guys.*
- *Hands on the console.*
- *Event production with character.*
- Specific numerics: guests, years, cues, partnerships
- Named venues: Hildene · Equinox Resort · Bennington Museum · SVCC · Arlington Common · Kimpton Taconic · Crooked Ram · Northshire · and peers

Tone: editorial, specific, calm. Write like a producer’s notes, not a brochure.

---

## 3. Voice — kill list

Banned across body, meta, OG, CTAs, and attributions:

| Kill | Replace with |
|------|----------------|
| Crystal-clear / stunning clarity | Concrete outcome or omit |
| Transform / transformation | What actually changes |
| Discover / Discover the Equinox Difference | Start a project / specific next step |
| Seamless | How the handoff actually works |
| Unforgettable | A memorable specific |
| Captivates your audience | What the room does |
| Professional audio visual services | SEO ballast only — never body voice |
| Get a Quote | **Start a project** |
| Elevate… (as CTA verb) | Start a project / Talk through [specific] |
| Wedding Couple / Event Partner (ghost attribution) | Named person · role · venue · date — or delete |
| “Let's start the conversation. We're ready to listen…” | Shorter promise + Start a project |
| ensure / ensures (as soft promise) | What you actually do or check |
| flawless / flawlessly | Concrete outcome or omit |
| Sound familiar? / Here’s the thing / Here’s the truth | Straight into the point |
| The Bottom Line (as H2) | A useful closing heading or none |
| At Equinox, we’re not just… / soft-sell closers | Specific next step or stop |
| After 20+ years… (identical lede frame) | Vary openings; keep career truth once, specific |
| Whether you’re planning… | Named venue, event type, or logistics fact |
| look no further / grab a cup of coffee / let’s dive | Cut |
| immersive / cutting-edge / world-class / peace of mind / magic happens | Specific claim or omit |
| Commitment to Excellence / Invisible Excellence | Operational title |
| meh → wow / transform your X | Concrete before/after |

**Write instead:** named rooms, cue times, gear that failed, guest counts, what the planner hears vs what FOH does. One claim per section. First-person OK on bylined articles when it’s specific, not templated.

## 4. CTA lexicon

| Role | Copy | Destination |
|------|------|-------------|
| Primary (sitewide) | **Start a project** | `contact.html` |
| Primary with arrow | **Start a project →** | `contact.html` |
| Secondary | Email / phone | Visible contact paths |
| Sticky mobile | **Start a project** | Same as nav |

Never: Get a Quote, Get Your … Quote, Elevate…, Discover…, Find Your Perfect…

Section headlines above CTAs may be specific (“Planning an event in Dorset?”) — the **link label** stays Start a project.

## 5. Page jobs (one claim per page)

| Page type | Job | Proof |
|-----------|-----|-------|
| Home | Thesis + character; invite into work | Event Spotlight, selected work, one quote, CTA |
| Work hub | Portfolio as credibility | Cards, Max Breath, CTA |
| Case study | One event, one story | Still opener, run-of-show, gallery, next case |
| Services hub / verticals | What we produce | Narrative + path to contact |
| About | Who and temperament | People, est. 2023, hospitality |
| Process | How we work | Steps without buzzwords |
| Insights hub | Field notes, not listicles | Teasers match article voice |
| Article | One useful claim | Byline, measure 62ch, CTA → Start a project |
| Regions / geo | Local discoverability **in brand voice** | Venue fluency, not quote mill |
| Contact | Reduce friction | Promise response time; wizard |
| Thank-you | Close the loop | Quiet confirmation, timeline |

---

## 6. Proof rules

- Prefer **named venues, dates, guest counts, cue times** over adjectives.
- Case studies: run-of-show sidebar is a signature Control Room organ inside Quiet Room — keep it.
- Testimonials: **Name · Role · Venue · Date** or omit entirely.
- Homepage proof: Event Spotlight + selected work — **no** second Ledger, **no** client logo marquee.
- Chamber / press badges: one quiet trust mark is enough.

---

## 7. SEO & geo pages

Geo pages exist for discovery. They must still sound like Equinox:

- Lead with venue fluency and production temperament, not keyword stuffing.
- CTA = Start a project.
- Avoid duplicated boilerplate sentences across markets when a local specific exists.
- FAQ / JSON-LD: factual and calm; no kill-list adjectives.

Deep SEO rewrites may be phased; voice and CTA compliance are non-negotiable now.

---

## 8. Meta, OG, social

- Brand name: **Equinox Audio Visuals** (not “EQX AV — Technical Producer”).
- Titles carry character or a specific event — not only category keywords.
- OG image / logo: full-color `assets/logo.png` where a mark is needed.
- Descriptions: one concrete sentence; Est. 2023 Manchester, VT when founding context helps.

---

## 9. Equinox Flow / ERP reuse

Reuse the same tokens and lexicon:

- Primary CTA string: `Start a project`
- Tagline: `Event production with character.`
- Colors / type / space: `design-system/tokens.json`
- Keep/kill lists above for any customer-facing copy in Flow (proposals, emails, status messages)

Do not invent a second “app voice” that sounds more SaaS than Equinox.
